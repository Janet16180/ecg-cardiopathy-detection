# ECG data sources and acquisition

This page records where waveform bytes come from. The [ECG-FM benchmarking repository](https://github.com/AI4HealthUOL/ecg-fm-benchmarking) is an index of datasets and evaluation code; it does not host these waveform collections. Downloading a dataset does not add it to the frozen training or evaluation cohorts. New use requires a separate waveform audit, patient/record identity rules, duplicate checks against all PTB-XL folds, and a defined label mapping.

See [data-quality-assessment.md](data-quality-assessment.md) for the current local EDA, task-specific scores, and a read-only preparation pipeline.

**Acquisition status, 25 September 2026:** Chapman/Shaoxing is complete: all **10,247** `.hea`/`.mat` pairs (**20,494 files**) passed the upstream SHA256 checks. CODE-15% is also complete: `exams.csv` and all **18** ZIP parts passed the Zenodo MD5 checks. The selected **200,000 MIMIC-IV-ECG recordings** are now downloaded and verified; the read-only waveform audit retained **197,207** from **40,568 patients**. Completion receipts establish file integrity and the stated signal checks, not label suitability.

The new public downloader writes a receipt with source URL, version, selection, local path, and verification progress. Its `complete` state means the downloaded files match upstream checksums; it does **not** mean the ECGs have passed the project's signal contract or are eligible for training. It can be rerun after interruption and reuses verified files. CODE-15% archives remain compressed to avoid storing a second full copy. The CODE-15% records are at 400 Hz and include shorter signals, so they require a new preprocessing and duration policy before model use.

The completed public acquisition was launched with `bash scripts/download_missing_ecg.sh` from the repository root. It used four PhysioNet workers to leave room for the separate MIMIC downloader. Check `data/acquisition/*.json` for final checksum receipts; rerunning the script reuses verified files. Its historical detached-job PID and log are in `outputs/data_acquisition/`. The earlier CODE-15% metadata-only check preceded the now-complete archive download.

The released [xECG model](https://huggingface.co/riccardolunelli/xECG_base_model_v1) is a pretrained checkpoint, not a waveform dataset. Our xECG fine-tuning reads PTB-XL; the queued continuation uses the frozen MIMIC/PTB-XL pool. The authors report pretraining on full CODE, Chapman/Ningbo and INCART in their [published paper](https://www.nature.com/articles/s41746-026-03196-y), which does not establish record-level independence from these public sources.

All Challenge files linked above carry the license and attribution terms on their PhysioNet release pages. Preserve the upstream metadata and cite the source dataset when publishing results.
