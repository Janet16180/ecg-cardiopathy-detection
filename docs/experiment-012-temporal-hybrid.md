# Experiment 012: compact temporal hybrid implementation

This implementation follows the authorized [architecture proposal](cross-domain-architecture-candidates.md#2-genomics-a-compact-mixture-of-temporal-scales) and the [common 25k study](nlp-inspired-25k-study.md). It is an ECG adaptation inspired by StripedHyena 2, not a replication of Evo 2. The [Evo 2 paper](https://www.nature.com/articles/s41586-026-10176-5) and [official implementation](https://github.com/ArcInstitute/evo2) describe a hybrid of short explicit, medium regularized, long implicit convolution operators and attention. Here there is no attention block, genomic vocabulary, imported genomic checkpoint, or claim of the source model's long-context throughput.

The original four-layer causal ECG CNN maps each independent five-second half to 79 tokens of width 256. Three residual gated blocks use channelwise causal filters of 5, 17 and 79 tokens. The short and medium filters are learned tap arrays; the long filter is generated by a 32-hidden-unit MLP of normalized lag with a fixed decay envelope. Each block projects values and a signal-dependent sigmoid gate, applies a linear FFT convolution with zero padding, and projects the gated result back to the residual stream. Its context and original CPC prediction heads retain the ordinary causal CPC objective at horizons 4, 8 and 12, the same exclusion mask, and the existing mean/max 512-feature downstream pooling.

The primary contrast is **mixed** versus **local**. Both arms have identical architecture, parameters and initial values. In the local arm, every medium and long filter coefficient is folded into five causal taps by lag modulo five and averaged within tap. Thus all coefficients stay trainable while every effective filter has at most five-token support. The same FFT implementation runs in both arms. The matched fresh GRU-CPC arm is a practical reference; its context parameter count is reported separately. All three share the same random stem and prediction-head weights. The absence of attention in both arms isolates temporal filter support.

The training input is exactly Experiment 019's source-stratified 25,000-record subset of the verified 115,359-record local cache. Selection seed 18046 must reproduce selected-index SHA-256 `43f405bfbddbb415f5072480744cebe6427afbeed2474a7be0e625cf1deac791`; exposure-order seed 18047 yields 115,359 examples and 902 updates at batch 128. The existing train-only normalizer is reused. All arms start fresh with seed 12012, AdamW learning rate 1e-4 and weight decay 0.01. The script records the exact source and input hashes. Each launch verifies the 13 GB training cache and the historical PTB readout cache against their receipts. The profile times a complete input and normalization pass over all 25,000 selected rows, 24 actual input-plus-GPU updates per arm, one checkpoint write/replay per arm, and 512 training-only PTB feature extractions per arm. The 7,200-second admission gate covers two training-plus-PTB preflights, two additional PTB preflights for the separate readout stages, measured profile work, 1.25 times the slower of update-based and full-pass input projections per arm, projected checkpoint writes, a second 512-record readout profile, 1.5 times full three-arm PTB extraction, 900 seconds for CPU fits/bootstrap/reporting, and 180 seconds of training reserve. Training writes resumable model, optimizer, RNG, update count and identity every 100 updates.

```bash
uv run --no-sync python -m scripts.experiments.run_cpc_temporal_hybrid012 --stage check
uv run --no-sync python -m scripts.experiments.run_cpc_temporal_hybrid012 --stage profile
uv run --no-sync python -m scripts.experiments.run_cpc_temporal_hybrid012 --stage train
```

The `check` stage is CPU-only. Profile checkpoints and CPC losses are not downstream performance results. The separate readout runner freezes the existing clean 15,359-label and nested 1,518-label training sets, 1,306 development ECGs from 1,173 patients, the historical PTB waveform cache, the training-only normalizer, and 512 pooled features per arm. It fits a train-only `StandardScaler` plus L2 logistic regression with `C=0.01`, `lbfgs`, 5,000 maximum iterations, tolerance `1e-8`, and seed 42. The primary development contrast is mixed minus local AUROC with 2,000 paired patient bootstrap draws at seed 12045; AUROC and average precision are reported for both label budgets. The GRU arm is descriptive. Its own profile again extracts 512 training records per arm and gates full extraction before any development score. Both the initial combined gate and readout gate must pass. No calibration or test labels are opened.

```bash
uv run --no-sync python -m scripts.experiments.run_cpc_temporal_hybrid012_readout --stage check
uv run --no-sync python -m scripts.experiments.run_cpc_temporal_hybrid012_readout --stage profile
uv run --no-sync python -m scripts.experiments.run_cpc_temporal_hybrid012_readout --stage run
```

The short 79-token sequence may make the long-support mechanism ineffective; FFT and filter-generation cost must be measured on the V100 before training.
