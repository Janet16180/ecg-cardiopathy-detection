# Can the MIMIC clusters expose CPC misses?

The previous HDBSCAN analysis grouped one ECG per patient using self-supervised
CPC features. Its CPC flag rate is not independent evidence of cardiopathy.
This audit therefore joins an **independent machine-generated interpretation**
from the official [MIMIC-IV-ECG v1.0 release](https://physionet.org/content/mimic-iv-ecg/1.0/)
by exact `study_id` and `subject_id`. The release's `machine_measurements.csv`
contains `report_0` through `report_17`, which are generated by the ECG machine,
not cardiologist adjudications. The source table is kept locally and verified
against the official SHA-256 manifest. Raw waveforms and existing model scores
remain unchanged.

Before inspecting the joined results, the disagreement definition is fixed:

- **Machine abnormal:** at least one report line exactly matches `Abnormal ECG`
  or `Summary: Abnormal ECG`, ignoring case, outer whitespace and terminal
  punctuation. Other wording is not silently converted to this category.
- **CPC negative:** the already saved Experiment 004 CPC calibrated probability
  falls below its original PTB-XL threshold, 0.2422915399. No threshold is
  changed using MIMIC.
- **Candidate disagreement:** both of the above on the same study and subject.
  Borderline, normal, conflicting, and unclassified machine lines are reported
  separately rather than treated as confirmed negatives.

The primary descriptive comparison is the candidate-disagreement rate among
machine-abnormal ECGs in each pre-existing cluster (`-1`, `0`, `1`). Also report
machine-interpretation coverage, the all-ECG counts, and the exact study IDs of
candidate disagreements. A small set of broad keyword categories in the
candidate machine text is counted separately as **text mentions**, including
possible and negated phrasing; these are not diagnosis labels. Since only one
ECG per patient was clustered, the
cluster analysis is patient-balanced; the all-ECG count is a separate view.
The audit also reports the largest ECG-machine (`cart_id`) share in each cluster
to screen for a simple device/source confound.

Machine interpretation and the CPC classifier are **two imperfect ECG readers**.
Their disagreement cannot establish a false negative, diagnose cardiopathy, or
estimate clinical sensitivity. A positive finding is a prioritized list for
blind cardiologist review or linkage to the actual cardiologist notes, with
both readers' outputs hidden from the reviewer. The MIMIC release provides
links to cardiologist reports; their text is outside this downloaded waveform
set. This report is exploratory and must not drive model selection on the
historical PTB-XL test cohort.

## CPC-negative-only clustering follow-up

The global one-per-patient clusters cover only 27 of the 119 candidate
machine/CPC disagreements. To test the user's missed-pattern question more
directly, cluster **all 4,782 CPC-negative ECGs** separately, before using their
machine reports. Freeze the same self-supervised CPC encoder and train-only
normalization, PCA to 16 components with seed 42, unit-length PCA vectors,
and Euclidean HDBSCAN with `min_cluster_size=50`, `min_samples=10`, excess-of-mass
selection. No machine text enters feature extraction, PCA or clustering.

Report machine-abnormal counts by cluster and noise, unique patients per
cluster, the largest single-patient share, and exact candidate IDs. Repeated
ECGs can make a dense group without indicating a common disease; patient
concentration is therefore a required check. Treat any apparent enrichment
as hypothesis-generating only, because the machine summary is not adjudicated
and this follow-up was motivated by the first exploratory result.

## Completed result, 26 September 2026

The 182,674,683-byte official machine table matched its published SHA-256
`56f6b1413221bce95bd6f48b28ca1acf27ae0b073d6f2c1d12f3af7500eabbb6`.
All **39,457** CPC-scored studies matched by both study and subject ID. Exact
machine summary categories were **17,631 abnormal**, **5,968 normal**,
**8,471 borderline**, and **7,387 unclassified**. There were no conflicting
exact summaries. Of 4,782 CPC-negative ECGs, **119** from **100** patients had
an explicit machine “Abnormal ECG” summary. This is **0.67%** of the
machine-abnormal subset. Conversely, **3,405 / 5,968 (57.1%)** machine-normal
ECGs were CPC-positive. These are disagreements between readers, not clinical
false negatives or false positives. The high machine-normal/CPC-positive count
reinforces that the PTB-calibrated threshold is not established for MIMIC.

In the original one-ECG-per-patient HDBSCAN sample, candidate disagreements
were **1 / 675 (0.15%)** of machine-abnormal ECGs in cluster 0, **6 / 255
(2.35%)** in cluster 1, and **20 / 1,508 (1.33%)** among unassigned ECGs.
The cluster-1/noise comparison is too sparse to support a distinct missed
condition pattern (two-sided Fisher p≈0.25; exploratory).

The separately frozen [negative-only clustering](../outputs/mimic_cpc_negative_clustering/report.json)
found two dense groups among the 4,782 CPC-negative ECGs. Machine-abnormal
summaries appeared in **24 / 919 (2.61%)**, **34 / 958 (3.55%)**, and **61 /
2,905 (2.10%)** ECGs in clusters 0, 1, and noise, respectively. The 34 in
cluster 1 represent **27 patients**. An ECG-level comparison of cluster 1 with
noise gives two-sided Fisher p≈0.016, but the simple patient-count comparison
is not convincing (27/606 versus 53/1,711 patients; p≈0.12). Repeated ECGs,
unequal missing-summary rates, post hoc follow-up, and imperfect machine text
make the ECG-level p-value exploratory. Cluster 1 spans 108 machine IDs and
its largest machine accounts for 14.9% of records, so no single machine alone
dominates it. This does not rule out acquisition effects.

Post hoc review triage found **37** candidate ECGs from **31** patients whose
machine text explicitly says “CONSIDER ACUTE ST ELEVATION MI”; **15** received
a CPC score below 0.1. They are distributed across the negative-only clusters:
**14** in cluster 1, **5** in cluster 0, and **18** unassigned. All 37 passed
the simple cached-waveform check used here: no flat lead and no sample above
5 mV; median maximum absolute amplitude was 1.53 mV. This does not establish
that the machine alert is correct, or rule out more subtle signal issues.
Eight of the lowest-scoring candidates were independently re-scored from the
cache with maximum probability error below 5e-9; their study/subject IDs also
matched the official `record_list.csv`.
