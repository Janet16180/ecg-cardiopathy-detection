# NTT-03 selection clarification

Before any real-ECG visual-model score, 18 October 2026. The scientific review noted that a criterion and
question class may occur under several source diagnosis names. Group explicitly by `(diagnosis, class_key)`,
then use the frozen lexical rule. Record unique target patients as well as question counts; repeat patients
across classes are dependent and support no independent-sample inference. Reject duplicate selected question
IDs rather than silently duplicating them. Every support remains in a nonzero inner fold and every target
in fold zero across all classes, preventing target/support overlap even when patients have several findings.

The NTT-02 phase comparator uses twelve leads; this pilot uses one supplied lead. Disclose that input
asymmetry. It is a strong contextual comparator, not a matched-input clinical contest. The selected-lead
answer is a supplied experimental input, never a successful prediction. No NTT-02 full-cohort integrity
replay is repeated: verify its saved hashes/inventory only before the already permitted selection.

The one-second candidate-crop view is the primary visual method; the full ten-second view is a fixed
secondary ablation. Apply the advancement rule to the crop view, never to the better of the two after
observing results. The chosen primary view addresses the known coarse temporal token grid; no real-ECG
visual score has been seen. Lead resolution rejects explicit disjunctions such as `lead V5/V6` or
`lead I and aVL`. Report every lead-link/exclusion category and retain the transform of each candidate.
