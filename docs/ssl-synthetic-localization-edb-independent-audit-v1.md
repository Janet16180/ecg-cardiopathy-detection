# Independent EDB annotation qualification audit

This prospective independent audit follows the committed EDB qualification protocol
and its annotation-contract clarification. Commit the checker and its executable
source admission before any actual independent annotation decode. Acquisition, qualification and this audit are separately measured attempts.
The initial acquisition41 failed before HTTP and remains charged. Later phases
append their actual predecessor, with no assumed stage number or skipped cost. No waveform,
model, disease score, training update or generator call is permitted.

The audit question is whether the retained public annotation interpretation is
reproducible from the admitted original bytes. A successful audit verifies that
interpretation; it cannot establish that a neural model localizes real disease.
The 79-subject publication claim and 78 explicit document-derived components remain
an unresolved source discrepancy, not grounds to invent another subject mapping.

It does not call WFDB's numeric byte decoder or the main episode/window functions.
For every record it verifies the complete seven-field ordered canonical-event
SHA256 and count against the main WFDB-derived raw stream. Separately reconstruct
the installed WFDB effective filter, retaining all removed indices. Sample-zero
NOTE is never automatically harmless metadata. Target parsing uses the full raw
stream, including valid sample-zero axis markers. Preserve all multiplicity,
negative SKIP diagnostics, unrecognized target candidates and structural failures.
No unrelated AUX text is emitted into audit receipts.

Read only the first three structural header lines after byte-hash verification.
Independently check record identity, two signals, 250 Hz and 1,800,000 samples and
retain literal native descriptions. Do not infer a twelve-lead representation or
parse header clinical comments. Any sanitized-header artifact is also hash checked.

Independently parse exact ASCII real ST/T and lowercase axis markers, with channel
from AUX, independently keyed by category/family/channel/polarity/extreme degree.
Original event order governs the active state. A peak on a boundary coordinate is
allowed only while that key is open; an equal-sample peak before its begin or after
its end remains orphaned. Preserve all peak samples/magnitudes and complete paired

pinned installed-standard symbol/description remain issues; exact restatements are
allowed. Extreme parent containment requires at least one valid matching base;
retain every matching parent ID and multiple-parent diagnostics without selecting
a favored parent or introducing a uniqueness gate. Global unrelated-event time decreases are diagnostics; invalid
quality chronology and invalid keyed coordinates are issues. Nothing is sorted or
repaired to create eligibility.

Reconstruct exact quality states, including UNKNOWN before the first update, all
nine subtype mappings and coincident updates in original order. Independently
compute every uint8 label and uint16 reason in the 90 by 2 by 720 grid, using
channel-local intervals, half-open intersection, explicit clean coverage, one

Recompute all episode, quality, channel, component and role summaries from those
