# Scientific continuation after public-wave measurement qualification

20 October 2026. Prospective design advice before LUDB outcome inspection. This document is a
review and prioritization note, not an executable protocol or authorization to score new endpoints.
The LUDB study tests whether the fixed derivative-energy proxy aligns with released QRS spans.
It cannot make existing generated masks into disease masks or rescue the failed PK scientific rule.

If the complete LUDB technical and scientific conjunction passes, use it as evidence that this
particular proxy has a QRS-related timing interpretation within annotated real-ECG intervals.
An unsuccessful result should be retained and understood at its stated level: malformed data or
failed integrity is technical; weak AP contrast is an unsuccessful timing-proxy qualification.
Do not tune the proxy on the160spent records until a separately frozen study defines new roles.

A small descriptive bridge to the generation objective is useful but secondary. Recompute the
exact previous128-seed generator-quality activity-coherence statistic on the same saved bank and
on LUDB's200records. Use only the physical leads I,II,V1..V6; preserve500Hz/5000-sample geometry.
The existing statistic squares prepend-first differences, smooths20samples, thresholds each lead
strictly above its own90th percentile, and averages28pairwise activity-mask Jaccards. Its paired
control independently circularly shifts each lead. Use the exact saved per-bank-index shifts and
reproduce the original128-seed primary/interval before any new result; define the public-record
shift seeds independently before evaluation. Both cohorts need the same full-record geometry.
Do not compare annotation-cropped LUDB sequences against full generated records. Full-record
coherence is a signal descriptor, while LUDB's QRS qualification only concerns its scored coverage.

The useful estimand is a descriptive real-minus-generated coherence distribution contrast with
separate whole-record/whole-seed uncertainty. There should be no equivalence, realism or clinical
PASS threshold. High coherence can also come from synchronized artifacts or implausible repetitive
signals. Distribution overlap establishes neither acceptable P/T morphology nor correct rhythm,
disease control, subject diversity, calibrated physical amplitude or privacy. This bridge can
contextualize the previously high generator coherence; it is not a substitute for localization.

The next primary learning question is transfer beyond the editor family used for training. Prefer
evaluating all frozen B/P/K/PK fits on independently committed, held-out numerical edit families
before training more models or choosing a winner. Candidate numerical families are a smoothly
windowed gain change, a compact-support local time warp, and a windowed frequency-limited
perturbation. Freeze exact family formulas, support/lead selection, amplitudes and seeds before
reading any evaluation maps; these are numerical interventions, not diagnoses. Preserve generator
lead algebra by editing native I,II,V1..V6 and rederiving canonical leads; determine support from
final numerical differences rather than editor intent. A time warp must keep outside-window
samples byte-identical, including its transition region, to yield honest masks.

Use fresh generator seeds, whole-seed paired inference and controls, every frozen model fit/arm,
and all prespecified families. Report full-grid AP, true-support-conditioned temporal ranking and
lead-presence separately. An oracle temporal measure cannot establish that a deployed method can
find leads. Predefine the primary across-family comparison and a per-family noninferiority guard;
do not adopt a successful aggregate while hiding one failed family. Treat high confidence on
unchanged controls as an independent endpoint, with fixed numerical interpretation rather than
clinical false-positive rates. Do not reinterpret the prior fourteen-of-fifteen conjunction as PASS.

Before even this bounded inference extension, repair resource forecasting prospectively. Profile
the actual generation, input assembly, inference, map persistence, figure creation and receipt/
hashing path on the shared GPU under the existing lock. Include measured disk I/O and conservative
whole-stage overhead; both previous fit studies exceeded optimistic wall/GPU forecasts despite
meeting hard caps. Freeze strict GPU-memory, free-memory, CPU/wall, retained-byte and total-stage
limits before profiling. A failure is preserved and charged, never a reason to repurpose the work
into unrelated classification. No new GPU training is necessary for this first transfer test.

If the held-out-family test still cannot sustain localization gains and control suppression
together, investigate the precise failure before expanding model count. If it succeeds, the next
prospective question can be annotation-informed synthetic augmentation for public waveform
localization. Any such training requires new patient roles and an actual-path training profile;
LUDB's entire160measurement cohort is then spent development evidence. Even a successful public
QRS/P/T task would measure wave localization, not regional real-disease localization.
