# Standalone public generator independent saved-output audit

19 October 2026. This prospective audit covers only the fresh standalone Pulse2Pulse
technical probe on this host. Historical factorial outputs are absent and are neither
reconstructed nor credited as verified evidence. Freeze this protocol and checker before
opening actual probe arrays. The coordinator admits exactly one run after source review.

The checker uses NumPy and CPU PyTorch independently of the generation/scoring module.
It verifies the committed main summary SHA and copied checker SHA supplied explicitly at
execution, every source snapshot and asset/output binding, fixed seeds and regenerated
float32 uniform noise, all four raw/export/canonical banks, and the saved first-input
replay. Export must equal float32 multiply 6000, truncation to int32 and transposition.
Canonical I, II, III, aVR, aVL, aVF and V1–V6 must satisfy the prescribed equations in
unverified author-export units, within absolute 1e-5. Every raw lead must vary and all
four raw outputs must differ. Inputs must remain byte-identical to their regeneration.

Strict `torch.load(..., map_location='cpu', weights_only=True)` opens only the declared
public checkpoint. It requires a nonempty finite float32 tensor dictionary and independently
computes its named tensor digest, compared to both main pre/post state digests. It performs
no architecture loading or model inference. Runtime state immutability, architecture
execution, exact forward counts and no-training claims are verified by source/receipt
bindings, not asserted as independently observed runtime events. Saved replay equality is
independently established; no second generator replay is implied.

Recompute all technical gates possible from saved arrays and check all reported gate
values and conjunction, six completed forwards, four completed seeds, no GPU/training/real
ECG/API use, one thread, false clinical/physical-unit/mask-control claims, profile forecast,
zero-based additive standalone accounting, file sizes and limits. Missing artifacts,
mismatches, or exceeded budgets yield FAIL and remain retained. No automatic retry.

The new audit directory is `pretrained_generator_standalone_v1/independent_audit_v1`.
Copy the committed checker there as `audit_script.py` and execute that exact file with
explicit `--root`, `--source-root`, `--main-sha`, `--script-sha`. The first root hosts
outputs; the second is the committed worktree whose source bytes were frozen by main. The audit refuses an existing summary or
failure receipt. Use CUDA hidden and OMP/OPENBLAS/MKL/NUMEXPR threads all 1. A fresh
120 CPU-second and 120 monotonic-wall-second cap, 2-second failure reserve, and 16 MiB
output cap are additional to the main 180 seconds/96 MiB. Hash reads check the deadline.
The audit writes an immutable additive prospective_ledger.json after hashing its success/failure
receipt. Terminal CPU/wall includes that receipt write/hash; ledger serialization follows the
measurement endpoint. It charges elapsed CPU/wall once, adds CPU to the standalone main cost and
keeps GPU-wall zero. It reports exact saved-output checks separately from source-bound
claims and includes final actual output bytes. No old stream costs or prior hashes are
reused as evidence. Read no raw/processed/closed ECGs, patient IDs or other outputs.

Only authored checker/tests, protocol and small aggregate audit report enter Git. Generated
waveforms, public weights and downloaded architecture stay local. This audit can establish
technical arithmetic/reproducibility integrity, not health, clinical normality, disease
control, valid mV calibration, or successful localization.
